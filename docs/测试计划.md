# mall-test-system V2 测试计划

## 1. 测试目标

验证地址归属、订单五状态流转、管理员权限、用户启禁用、参数校验、商品软删除和数据库一致性，覆盖正常路径、非法状态、越权和并发重复请求。

## 2. 测试范围

- 认证与用户启禁用
- 收货地址增删改查、唯一默认地址和归属校验
- 商品分页、库存边界、上下架与软删除
- 购物车增删改查
- 创建订单、地址快照、商品快照和库存扣减
- 支付、取消、发货、确认收货及重复操作
- 用户订单分页筛选、管理员订单组合查询
- 状态日志时间线
- 400 / 401 / 403 / 404 和统一响应格式
- MySQL 锁、事务回滚、库存只恢复一次

## 3. 不在范围

- 真实支付、退款、优惠券、评价、秒杀
- Redis、消息队列、搜索引擎
- 未经单独安排的性能容量结论和生产安全认证

## 4. 环境

| 项目 | 内容 |
| --- | --- |
| 后端 | Spring Boot 2.7 / Java 8 |
| 前端 | Vue3 + Vite + Element Plus |
| 数据库 | MySQL 8.0 / InnoDB |
| 接口 | Swagger UI、Postman |
| 部署 | Docker Compose + Nginx |

## 5. 测试策略

1. 先执行 `sql/init.sql` 获得固定基线数据。
2. 依次验证公开接口、普通用户接口和管理员接口。
3. 每个状态动作同时检查 HTTP 响应、`orders`、`order_status_log` 和商品库存。
4. 对取消、支付、发货、确认收货发送重复请求，检查错误信息和数据不重复变更。
5. 使用两个并发取消请求验证订单锁和库存只恢复一次。
6. 修改或删除地址后检查历史订单快照保持不变。
7. 软删除商品后检查前台、后台默认列表、上架接口和历史订单明细。

## 6. 准入条件

- 后端 `mvn test` 和前端 `pnpm build` 可执行。
- MySQL 初始化脚本可在空测试库执行。
- 三个默认账号和五状态订单存在。

## 7. 准出记录

测试结果、用例数量、缺陷数量和结论必须在实际执行后填写到模板，不允许用预估值或示例值代替。
