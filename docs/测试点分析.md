# mall-test-system V2 测试点分析

| 模块 | 正向测试点 | 反向与一致性测试点 |
| --- | --- | --- |
| 登录 | 启用用户、管理员登录成功 | 错误密码、禁用用户、超长字段、错误 JSON |
| 权限 | 各角色访问授权接口 | 无 token 401、无效 token 401、USER 访问后台 403 |
| 地址 | 新增、修改、删除、查询、设置默认 | 必填/长度、操作他人地址、并发设置默认、删除默认后重新选默认 |
| 商品 | 搜索、分类、分页、上下架、库存修改 | 非法分页、负库存、下架商品加入购物车、软删除后查询/编辑/上架 |
| 购物车 | 新增、合并数量、修改、删除 | 数量 0、超过库存、操作他人条目、已下架或删除商品 |
| 创建订单 | 全部/选中条目下单、扣库存、清购物车 | 缺少 addressId、他人地址、空购物车、库存不足、商品下架、并发下单 |
| 支付 | CREATED 变 PAID并写日志 | CANCELLED 支付、重复支付、他人订单 |
| 取消 | CREATED 变 CANCELLED、库存恢复、写日志 | PAID/SHIPPED/COMPLETED 取消、重复取消、并发取消库存只恢复一次 |
| 发货 | ADMIN 将 PAID 变 SHIPPED并保存物流 | USER 发货、缺失/超长物流字段、非 PAID 发货、重复发货 |
| 收货 | 所属用户将 SHIPPED 变 COMPLETED | 他人订单、非 SHIPPED、重复确认、管理员调用用户接口 |
| 订单查询 | 用户状态分页、管理员五条件组合查询 | 非法状态、page=0、size=0/101、错误时间格式、开始晚于结束 |
| 状态日志 | 五种动作日志字段完整且按时间正序 | 主事务回滚时不能单独留下日志 |
| 地址快照 | 详情展示下单时地址 | 修改/删除源地址后快照不变 |
| 用户管理 | 查询、启用、禁用普通用户 | 重复启禁用、修改管理员、禁用后旧 token 失效 |
| 统一异常 | 400/401/403/404 均为统一 JSON | 类型错误、格式错误、未知资源、未知接口 |

并发场景应记录请求时间、响应、事务结果和数据库前后值；未执行时不填写通过率或缺陷数量。
