## 6. 风险说明

- 当前项目使用模拟支付，不接入真实支付渠道。
- 用户密码使用 BCrypt 存储；初始化演示账号仍使用弱口令，仅适合测试环境，云部署时必须通过 `.env` 覆盖管理员密码。
- token 存储在后端内存中，服务重启后需要重新登录。
